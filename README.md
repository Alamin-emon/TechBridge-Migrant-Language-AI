# TechBridge-Migrant-Language-AI
AI-powered vocational language learning platform for migrant workers in Italy, featuring technical glossaries, workplace simulations, and certification support.

**Bridging the Vocational Language Gap for Migrant Workers**

TechBridge AI is an AI-powered platform designed to help migrant workers in Italy overcome vocational language barriers. By focusing on trade-specific terminology and real-world simulations, the platform accelerates the transition from unskilled labor to certified professional roles.

## 🚀 Key Features

* **📊 Student Dashboard:** Track progress in language mastery and certification readiness.
* **🎭 AI Roleplay:** Practice real-world workplace scenarios (e.g., talking to a supervisor or client) using AI-driven conversational agents.
* **📚 Technical Glossary:** Access trade-specific terms with translations, simplified Italian definitions, and visual aids.
* **🤖 AI Skills Alignment:** Matches existing worker skills with Italian certification standards.

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** CSS3 (Custom properties & Responsive design)
* **Project Documentation:** PDF Final Report included in `/docs`
* **AI Integration:** Large Language Models (LLMs) for simulation and terminology extraction.
